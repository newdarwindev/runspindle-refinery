# Historical experiment reference

`experiment-helper.py.txt` preserves the selected legacy Python DSPy helper as inert review material. It is not imported or executed by the new refinery package. Source IDs resolve to private original locations; original rights remain unchanged.

Retained design anchors include a DSPy summarization signature, replayable-case filtering, latency accounting, bounded optimizer configuration, digest-shaped promotion checks, an approval record and rollback history. These anchors are migration evidence, not complete security or evaluation controls.

Required adaptations are specified in [experiments](../../specs/experiments.md): verify artifact bytes, authenticated approval and leakage-safe partitions; measure real cost and safety; enforce cumulative provider budgets; use atomic concurrent registry updates; verify serving readback and explicit rollback targets. The historical `max_calls` argument is not an enforced global budget, and a Boolean approval field is not authentication.

DSPy is an external dependency, not copied here. No package installation, provider call, data transmission, optimization or candidate promotion was performed. Syntax and exact body preservation can be checked without executing the helper.
